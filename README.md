# Real-Time-Character-Counter-Using-JavaScript
This project is a modern and interactive Real-Time Character Counter developed using HTML, CSS, and JavaScript. The application allows users to type messages inside a textarea while dynamically tracking the number of characters and words entered in real time.

The project displays the total number of characters typed, remaining characters, and total word count. A progress bar visually indicates the character usage limit. The application also prevents users from typing beyond the maximum character limit of 200 characters and displays a warning message when the limit is reached.

Additional features such as a Copy Message button, Clear Message button, dynamic color changes near the character limit, and responsive glassmorphism UI design are included to improve user experience and functionality.

## Features

* Real-time character counter
* Remaining character counter
* Word counter
* Progress bar
* Character limit restriction
* Warning message on limit exceed
* Copy message feature
* Clear message feature
* Responsive modern UI design

## Technologies Used

* HTML5
* CSS3
* JavaScript
